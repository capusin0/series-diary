## Firebase setup
1. Create a Firebase project.
2. Add a Web App.
3. Enable Authentication > Anonymous.
4. Create Cloud Firestore.
5. Replace the values in firebase-config.js with your Firebase web config.
6. Publish the rules from firestore.rules.
